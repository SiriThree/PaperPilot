# D 安全边界与验收约定

适用范围：三类项目统计、项目资源授权、C 的不可信来源处理和审计。本文对应 PRD FR-01、FR-05、FR-07、FR-08、9.5；不是对未知攻击或生产环境的全面安全保证。

## 信任边界

| 边界 | 不可信输入 | 服务端约束与验证 |
|---|---|---|
| 用户到会话 | 用户名、密码、Cookie、请求头 | B 的 credentials 模式验证摘要及会话；development 仅用于显式标记的测试。请求编号不是身份凭据。 |
| 会话到项目 | 路由中的项目、论文、任务、报告编号 | 每次查询最新成员关系；owner 才能管理成员、移出论文和读取完整项目审计。资源替换返回统一不可访问错误。 |
| 论文到 C | PDF 文本及其中的指令 | 项目及选定论文在检索前限定；正文作为数据进入模型，无工具调用；返回引用必须属于实际输入片段。 |
| 模型到网关 | 候选 SQL、伪造的项目条件、函数和结构 | SQLGlot AST 完整允许清单；仅三类 SELECT；从可信模板重建并绑定服务端项目参数。拒绝未知、解析失败及不支持结构。 |
| 网关到数据库 | 即使网关存在缺陷的查询计划 | 执行器再次验证计划；每项目独立登录、只读事务、安全屏障视图及 SESSION_USER 绑定；禁止底表读写和危险角色权限。 |
| 服务到审计 | 查询结果、异常、重复事件及权限漂移 | 独立追加写身份、执行前后持久化门槛、事件指纹幂等；失败不执行或不返回结果；不自动重试未知提交。 |
| 配置到进程 | 连接配置、凭据文件和部署变更 | 配置来自可信操作员；不接受 HTTP 凭据或 Context；凭据不进入日志、报告或仓库。 |

数据库管理员、OS 管理员、安装迁移的操作员和同一服务账户下的进程属于可信部署边界。D 审计只允许执行迁移 006 定义的指纹函数，逐事务验证固定函数体、属性及授权，不能用“允许任意 SECURITY DEFINER”解决兼容问题。管理员并发改变函数/视图仍存在检查与执行间窗口；需在维护窗口配置角色，不能据此宣称抵御恶意 DBA。

## 权限矩阵

| 操作 | owner | member | 非成员／未登录 |
|---|---|---|---|
| 文献研究、报告、安全统计 | 允许当前项目 | 允许当前项目 | 拒绝 |
| 成员管理、移出论文、项目审计 | 允许当前项目 | 拒绝 | 拒绝 |
| 任意 SQL／模型写库／未知操作 | 拒绝 | 拒绝 | 拒绝 |

最新角色在生成候选后、执行前及返回结果前再次核验；已执行的 SQL 不能因后续撤权而被宣称为“未执行”。撤权阻止后续请求和结果返回，不承诺回溯取消所有正在运行的事务。

## 允许查询与资源限制

允许按年份计数、按主题计数和未完成证据提取的论文列表。视图/字段见 `backend/app/security/sql_policy.py`，拒绝类型包括 UNSUPPORTED_QUERY、SQL_POLICY_REJECTED、QUERY_TIMEOUT、QUERY_RESULT_TOO_LARGE、GATEWAY_UNAVAILABLE 和 AUDIT_UNAVAILABLE。执行默认 3 秒、100 行、完整响应 256 KiB；取消后等待连接清理。

原生 D 使用数据库安全屏障视图和 SESSION_USER 绑定，并非底表全部启用原生 RLS。此方式必须按实际隔离与权限测试验收，不因没有改造全部底表而判为失败。

## 候选来源与实验边界

当前产品使用三条固定模板降级，`policy_id` 后缀为 `-template`。可信测试注入的候选使用 `-injected`；该标记不表示真实模型已经接入。未来模型查询必须采用独立来源记录与数据集，不得借用模板通过率。

十项 C/D 提示词回归含五项恶意用户输入、五项恶意论文正文，运行真实 PDF 解析和 C 引用校验；模型传输是故意返回攻击者要求结果的受控替身。它验证即使模型服从攻击者也不能扩大来源权限或执行数据库工具，不测量实际模型拒绝恶意指令的概率。

三组安全实验和原始结果见 [实验说明](security-evaluation/README.md)。生产身份供应、真实模型质量、第二台机器部署及现场演示仍需各负责人按交付计划共验。
