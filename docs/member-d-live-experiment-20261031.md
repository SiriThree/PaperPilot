Alice 登录 → D contract A → 查询与审计 → 攻防实验 → **开始实时实验**。页面实际启动固定脚本，在专属临时 PostgreSQL 中运行三种防护配置；完成后展示同一任务的新结果，可下载当前 JSON。任务期间隐藏历史通过率，刷新后通过只读查询恢复进度。同一后端进程只允许一个任务；相同负责人重复提交正在运行的任务会返回原编号。
