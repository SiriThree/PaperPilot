# Chen 式 E-R 图图例与联系基数

## 图形含义

| 图形 | 含义 |
| --- | --- |
| 矩形 | 实体或关系模式阶段的联系实体，中文名下附英文标识 |
| 椭圆 | 实体属性，中文名下附字段名；实下划线表示主键分量，虚下划线表示部分键（须与所属实体主键组合） |
| 菱形 | 两实体之间的联系，不代表新增一张表 |
| 连线 1 / N / M | 最大联系基数；左 1 右 N 为一对多，反向为多对一 |
| 跨线弧 | 总图“保存”与“导入”的一处交叉，表示两条线不相交 |

例如：项目与论文导入为 1:N，即一个项目可有多次导入，而一次导入只属于一个项目；论文元数据与项目导入为 1:1。概念图中论文—作者、论文—主题画作 M:N 菱形，最终关系模式以关联实体拆为两条 1:N。

图中 1/N/M 只标最大数量，不声称所有联系均必须存在。任务可以尚无成功结果；最小数量以以下表格及 AB-1 为准。项目必须至少一位成员、证据结果恰好五个证据字段等额外约束，见最终模型 K01—K15。可空性不单独标记，见数据字典。

## 修改与重新生成

绘图源为 `scripts/render_chen_clean.py`，实体、属性与联系以手工坐标布局内嵌其中。修改模型时先同步数据字典与需求/冲突说明，再更新脚本中对应视图并重新生成。

在仓库根目录执行：

```powershell
python scripts/render_chen_clean.py --check
```

脚本只使用 Python 标准库，输出 5 张 SVG 到 `diagrams-chen-clean/`，不会改动其他目录。`--check` 会检查关系线交叉（仅放行总图标了 hop 的“保存×导入”一处）、连线穿过其他实体/菱形/椭圆、包围盒重叠和文字溢出，发现问题即以非零码退出。SVG 为静态矢量图；浏览器可放大查看。
